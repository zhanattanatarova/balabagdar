# Главная: популярные и ближайшие клубы

## Что изменится
- «Популярные кружки» покажет не более 10 карточек и будет сортироваться по заполненности фото и цены, затем по отзывам и просмотрам.
- «Все →» откроет полный каталог центров и кружков.
- Вместо дублирующего списка появится кнопка «Показать рядом со мной».
- Геолокация будет запрашиваться только после нажатия этой кнопки.
- «Рядом с вами» появится только после успешного определения местоположения и только для клубов с доступными координатами; карточки получат расстояние в километрах.
- Автоматический запрос геолокации при первом открытии сайта будет убран.

## Технические детали
- Добавить клубам счётчик просмотров и безопасное увеличение при открытии карточки.
- Добавить необязательные координаты клуба; при поиске рядом использовать сохранённые координаты, а для текущих записей пробовать определить их по адресу только после нажатия кнопки.
- Добавить переводы новой кнопки и сообщений для РУ / ҚЗ / EN.
- Проверить главную без разрешения, при отказе и при успешной геолокации.
